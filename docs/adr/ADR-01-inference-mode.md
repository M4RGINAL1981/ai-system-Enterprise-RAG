### ADR-01: Выбор режима инференса
* **Статус:** Принято (Accepted)
* **Контекст:** Система Enterprise RAG предназначена для интерактивных ответов на вопросы сотрудников в реальном времени.
* **Рассмотренные альтернативы:** 1. Synchronous REST API (FastAPI) 2. Asynchronous Message Queue (Kafka).
* **Решение:** Выбран синхронный REST API (FastAPI).
* **Обоснование:** Обеспечивает простоту реализации, минимальные накладные расходы и задержки (Low Latency) при одиночных запросах пользователей, а также достаточную пропускную способность на первом этапе проекта.
* **Последствия:** При экстремальных пиковых нагрузках возможен рост времени ожидания ответа, что потребует горизонтального масштабирования инстансов приложения.
